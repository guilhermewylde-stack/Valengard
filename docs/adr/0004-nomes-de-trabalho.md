# Nomes com risco de IP são nomes de trabalho

Os nomes marcados com ⚠ em `docs/lore/LORE-LEGADO.md` (Condado, Khazrum, Smaugor, Morgrath, Uruk, Mão Branca, "Você Não Passará", Aerandir) ficam durante o desenvolvimento e o teste fechado, por gosto do jogador-autor, e são trocados antes do primeiro lançamento público (itch.io aberto, Play Store, Steam). Como todo texto vive em arquivos de tradução, a troca é só editar chaves; uma remoção da loja levaria as compras dos jogadores junto.
