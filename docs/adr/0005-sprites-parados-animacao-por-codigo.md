# Sprites parados do Gemini, animação por código

Cada herói e monstro tem 3 imagens paradas (sul; norte e leste por edição sobre a do sul; oeste espelhado), e andar, atacar, dano e morte são animados por código. No projeto LOTR o Gemini acertava a pose de referência mas não mantinha o personagem entre quadros, e a saída que funcionou (copiar moldes do Tibia) não serve para um jogo comercial.

## Considered Options

- Base livre animada (LPC): traço e tamanho próprios, CC-BY-SA na arte derivada.
- Base de caminhada desenhada à mão, vestida pelo Gemini: plano B, só para o herói, se o teste de 3 direções falhar.
